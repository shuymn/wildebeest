# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: on [shuymn/kopje](https://github.com/shuymn/kopje), open Security,
then **Report a vulnerability**. Please do not open a public issue or pull request for it.

Include what is affected (the Kopje version, and the endpoint or command), how to reproduce it, and what an attacker
gains. The fix is released first and the advisory is published after it.

## Supported versions

Security fixes go into the latest release only. Kopje is pre-1.0: upgrade to the latest version to receive them.
